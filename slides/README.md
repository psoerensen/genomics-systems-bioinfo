# Slides

`introduction_genomics_systems_bioinfo.qmd` provides the common lecture overview and a discussion prompt for each reusable block. Detailed models, runnable examples, exercises and solutions are in the B-numbered modules and practicals.

Render from the course root:

```bash
quarto render slides/introduction_genomics_systems_bioinfo.qmd
```

The website project writes the deck to `docs/slides/`. Speaker notes are hidden in the standard presentation. Audio narration has not been created.
