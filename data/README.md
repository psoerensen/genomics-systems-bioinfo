# Teaching data

All executable examples currently use hypothetical data generated by `R/teaching_data.R` or small literal inputs in the practical. No private observations or biological downloads are required.

The fixture has 48 animals, 24 count features, 8 log2 protein-abundance features, 6 log2 metabolite features, 6 microbial count features and 8 diploid genotype dosages. Metadata specify animal identity, diet, batch, sex and farm. `response` uses arbitrary recorded units. Diet is allocated at animal level in this hypothetical design. Counts follow a negative-binomial generating model with size 12 and known library-exposure factors. Other assay values and feature-to-gene mappings are fictional and establish no biological findings.

The fixture creates known shared latent variation in protein, metabolite and phenotype measurements. Association in these examples is a property of the generating model, not evidence that a measured feature causes a production trait. Calling the function resets R's random generator to its supplied seed. Changing the seed changes the realization while preserving the model.
