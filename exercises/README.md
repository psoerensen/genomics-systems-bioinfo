# Exercises and assessment

Every reusable module and practical contains exercises followed by collapsed suggested answers. Attempt the exercise before revealing the answer; identify the analysis unit, denominator, transformation and model assumptions in the response.

Both course pathways may use the same core exercise. Select a distinct extension when students take both pathways: computational model/validation comparisons for the GSB route; sampling, assay choice and integration interpretation for the Multi-Omics route. The curriculum map preserves the supplied formal assessment weights; these exercises do not replace the agreed assessment scheme.

A final computational report should state the question and units, show data/identity checks, document exclusions and transformations, justify its models and evaluate them on suitable units. A final proposal should connect biological objectives to replication, sampling, assay feasibility, analysis, validation and data governance. Neither assessment should reward a biologically attractive claim beyond the evidence presented.
